# 联机机器人 — 命名规范

> **标识符词表与前缀 SSOT。** 改 Bot / 扩展或消费 `NetworkRelayServer` 公开面时必读。  
> ECS/Burst 形态（`__` 私有字段、Job 分层、热路径禁 Complete）见工程 `.cursor/rules/zg-ecs-style.mdc`；本文件管 **Relay / Bot / Server 对齐的命名**。

**权威对照代码**：`NetworkRelayServer`、`NetworkServerSendBuffer`、`NetworkRelayServerIdentity`（`ZGUPEntitiesNetworkingCommon`）。

---

## 1. 范围

| 适用 | 不适用 |
|------|--------|
| `Terminator.MultiplayerBot*` 新类型 / 字段 / 配置键 | 游戏 UI、排位表现层（可用中文表头） |
| Bot 消费或扩展的 `NetworkRelay*` / `NetworkRelayServer*` 公开 API | 为 Bot 特化的 Server 方法名（禁止，见架构 M3） |
| `BotConfig` / `BotRelayFarmTickConfig` 平行字段 | 历史测试夹具内部别名（新代码不得扩散） |

## 2. 前缀与后缀

### 2.1 Server / 协议（NetworkingCommon）

| 前缀 | 含义 | 示例 |
|------|------|------|
| `NetworkRelay*` | 协议共享类型 / 枚举 | `NetworkRelayMatch`, `NetworkRelayMessageType` |
| `NetworkRelayServer*` | Server 所有权组件 / Job 载体 | `NetworkRelayServer`, `NetworkRelayServerMatch`, `NetworkRelayServerIdentity` |

### 2.2 Bot（ZGUPTerminator）

| 前缀 / 后缀 | 含义 | 示例 |
|-------------|------|------|
| `BotRelay*` | 传输、Farm、Wire、inject、Tick | `BotRelayFarmNative`, `BotRelayInjectQueue` |
| `Bot*`（无 Relay） | Agent / Session 状态与逻辑 | `BotAgentState`, `BotAgentLogic`, `BotState` |
| `BotMatch*` | **仅**匹配租约 / Farm 互斥 | `BotMatchGuard`（不是 `BotRelayMatchGuard`） |
| `BotReplay*` / `BotRecording*` | 回放与录制 | `BotReplayLogic`, `BotRecordingBlob` |
| `*Ops` | 静态 Burst 操作入口 | `BotRelaySlotOps`, `BotRelayPopEventsWalkOps` |
| `*System` | ECS 系统 | `BotRelayPostTickSystem`（经 AgentSystem 文件） |
| `*Host` | 托管生命周期 | `BotRelayWireCatalogHost` |
| `Farm*` | 多 agent SoA | `BotRelayFarmConfig`, `BotRelayFarmTickConfig` |

### 2.3 大小写

| 层级 | 规则 | 示例 |
|------|------|------|
| 类型 / 公开方法 | PascalCase | `Schedule`, `Matching`, `AsReadOnly` |
| **公开属性 / 公开字段 / Job 字段** | **camelCase**，与私有 `__stem` 同词干 | `matchCount`, `matchIDs`, `identities` |
| 私有实例字段 | `__camelCase` | `__matchIDs`, `__identities` |
| 私有方法（Bot / ZG 风格） | `__PascalCase` 或 `__camelCase`（与文件既有一致） | `__StartMatching`, `__TickState` |

## 3. 匹配 / 组队词表

| 概念 | 正确命名 | 禁止 |
|------|----------|------|
| 匹配池成员 userID 列表 | `matchIDs`（`__matchIDs`） | `MatchPool`, `MatchPoolUserIDs`, `UserIDs` 作池同义词 |
| 每 identity 匹配负载 | `matches` / `NetworkRelayServerMatch` | 另造 `MatchEntries` |
| 段位距离桶 | `matchDistances` / `matchDistanceIDs` | — |
| 池大小（公开） | `matchCount`（=`matchIDs.Length`） | 与 `__matchCount` ID 生成器混淆为「池人数」语义时须注释 |
| 协议：进入匹配 | `Matching`（方法 / `NetworkRelayMessageType.Matching`） | — |
| 协议：撮合成功 | `Match` / `MatchToRead` / `MatchToSend` | — |
| 协议：取消 | `Mismatch` | — |
| Bot 配置零基段位 | `matchLevel`（= `MatchToSend.level` / 真人 `sourceRank`） | — |
| Bot 会话当前撮合代次 | `session.matchID`（非零仅由 MatchToRead 写入） | 与 `matchIDs` 池列表混淆 |
| 邀请响应延迟配置 | `inviteTimeoutMin` / `inviteTimeoutMax` | — |
| 观察到真人进池后再派 Bot 的等待窗口 | `matchTimeoutMin` / `matchTimeoutMax` | `reactiveMatchDelay*` 等非平行名 |

文档叙述可用「匹配池」，**API 标识符必须用上表词干**。

## 4. 只读投影（Server → Bot 热路径）

### 4.1 推荐形态

当 ≥3 个只读视图常一起传入 Job 时，使用嵌套 **`ReadOnly` + `AsReadOnly()`**（对齐 `NetworkServerSendBuffer`）：

```csharp
// NetworkRelayServer — 持 NativeList 句柄 + [ReadOnly]，勿在主线程对未完成 Job 的 list 调 AsArray()
public struct ReadOnly
{
    [ReadOnly] public NativeList<uint> matchIDs;
    [ReadOnly] public NativeList<NetworkRelayServerMatch> matches;
    [ReadOnly] public NativeList<NetworkRelayServerIdentity> identities;
    public NetworkServerSendBuffer.ReadOnly sendBuffer;
}

public ReadOnly AsReadOnly();
```

单个标量或已有公开面保持 camelCase 属性（如既有 `matchCount`）。

### 4.2 消费约定

- Bot PostTick 已 `UpdateAfter(NetworkRelayServerSystem)`：用 `state.Dependency` 串联，**禁止**热路径 `JobHandle.Complete()`。
- **禁止**经 `NetworkRelayServerManager.server` / `GetServerStatus` 读池（内部 Complete）。
- **禁止**在主线程对仍被 Server Job 写入的 `NativeList` 调用 `AsArray()` / `AsReadOnly()` 数组投影（会强制要求 Complete）；只把 list 句柄传入依赖链上的 Job。
- Server **不**按 Bot 身份过滤；「是否真人」仅 Bot 侧 `BotMatchGuard.IsFarmBotUser`。
- 只出 `ReadOnly`；禁止把可写 `NativeList` 所有权交给 Bot。

## 5. 配置平行命名

| 语义 | 字段 |
|------|------|
| 世界邀请 → Join 随机延迟 | `inviteTimeoutMin` / `inviteTimeoutMax` |
| 观察到非 Bot 进入 `matchIDs` → 派遣 `MatchToSend` 前随机等待 | `matchTimeoutMin` / `matchTimeoutMax` |
| 匹配就近并列种子世代（每次重进池 +1） | `matchObserveGeneration` |
| 每 Bot 段位 | `botProfiles[].matchLevel` |

`BotConfig` → `BotRelayFarmConfig` / `BotRelayFarmTickConfig` 拷贝时字段名保持一致。

---

## 6. 反例

| 错误 | 原因 |
|------|------|
| `MatchPoolUserIDs` / `Matches` / `Identities` 作公开属性 | 发明同义词 + PascalCase，违反 Server camelCase 词干 |
| `GetHumanMatchingSnapshot()` | Bot 特化 Server API，违 M3 |
| `reactiveMatchDelayMin` | 未与 `inviteTimeout*` 平行 |
| 热路径反射 `__identities` | 非 Burst；测试 probe 不得升格为生产 |
| 主线程扫 `matchIDs` 前 `Dependency.Complete()` | 违架构 D2 |
